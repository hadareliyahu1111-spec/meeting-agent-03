# Meeting Agent - מטלה 03

## תיאור
סוכן AI אוטונומי המחבר בין Gmail ו-Google Calendar.

## קוד קבוצה
bdikahadar  (עדכני לשם הקבוצה שלך)

## הרצה
1. התקני תלויות: python -m pip install google-auth-oauthlib google-auth-httplib2 google-api-python-client
2. הרצי OAuth: python oauth_setup.py
3. שליחת מיילי בדיקה: python send_test_emails.py
4. הפעלת הסוכן: python meeting_agent_simple.py

## קבצים
- oauth_setup.py - הגדרת הרשאות
- send_test_emails.py - יצירת מיילי בדיקה
- meeting_agent_simple.py - הסוכן האוטונומי
- PRD.md - מסמך דרישות
- PLAN.md - תכנית עבודה
- TODO.md - רשימת משימות
